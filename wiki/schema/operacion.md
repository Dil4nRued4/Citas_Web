# Operación de la Wiki frontend

Las reglas normativas están en [`../AGENTS.md`](../AGENTS.md).

- **INGEST**: verificar si la fuente es requisito, diseño aprobado o implementación observada; sintetizarla y enlazar Wiki global/API; actualizar índice y log.
- **QUERY**: empezar por el índice local, luego consultar contexto global/API; validar stack, UI y contrato en los archivos reales.
- **LEARN**: guardar conocimiento durable explícito; no elevar diseños propuestos o requisitos a decisiones aprobadas.
- **LINT**: revisar contradicciones, enlaces, páginas huérfanas y privacidad; contrastar integración con API y resumen global.

No documentar componentes, endpoints, estados visuales ni tests como hechos hasta que existan y se comprueben.
